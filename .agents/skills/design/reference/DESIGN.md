# Jade Obsidian Design System

## Core Philosophy
Jade Obsidian is a professional, high-contrast design system built for technical and research-oriented content. It balances a deep, authoritative green with clean, structured layouts and tactile elevation.

## Color Palette

### Primary & Accents
- **Jade Obsidian (`#1A6B5A`)**: The primary brand color. Used for headings, logos, and primary action buttons.
- **Marigold (`#D17A00`)**: A secondary accent color. Used for meta-information, highlights, and subtle call-to-actions.

### Surfaces
- **Surface (`#F9F9F9`)**: The main page background. A soft, clean off-white.
- **Surface Bright (`#FFFFFF`)**: Used for elevated cards, containers, and sections to provide depth.
- **Surface Dim (`#DADADA`)**: Used for borders and subtle dividers.

## Typography
- **Primary Font: Outfit**: Used for headings and branding. Its geometric clarity provides a modern, technical feel.
- **Secondary Font: Space Grotesk**: Used for body copy and navigation. Offers high readability for long-form research content.

## Visual Language
- **Homogeneous Surfaces**: Following the removal of the grid pattern, the system relies on solid color fills and subtle borders for structure.
- **Tactile Elevation**: Elements use sharp borders and minimal shadows to create a "paper-stack" feel, emphasizing content hierarchy without excessive depth.
- **Professional Contrast**: High contrast between text and background ensures accessibility and clarity for complex technical documentation.
